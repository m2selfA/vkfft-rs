# Security Policy

## Supported versions

`vkfft-rs` is still pre-1.0. Security fixes are applied to the current `main` branch; older development snapshots are not maintained as separate supported release lines.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private **Security Advisories / Report a vulnerability** flow for this repository so details can be reviewed before disclosure.

When possible, include the affected backend or feature set, a minimal reproducer, expected versus observed behavior, and whether the issue requires a specific GPU driver or device capability.
